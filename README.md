# RoLookup | Roblox User Lookup Web App

A modern Flask web application for looking up public Roblox user profiles.  
Built with Python, Flask, Bootstrap 5, and Roblox public APIs.

> This project is not affiliated with, endorsed by, or sponsored by Roblox Corporation.

---

## Features

| Feature | Description |
|---|---|
| **Profile Search** | Search for any Roblox user by username |
| **Avatar Display** | View headshot and full-body avatar images |
| **User Details** | Display username, display name, user ID, verified badge, and ban status |
| **Social Stats** | Show friends, followers, and following counts |
| **Account Age** | View join date, account age, and a visual account age progress bar |
| **Group Memberships** | Display groups, group icons, and user roles |
| **Created Games** | Show games created by the user with thumbnails and visit counts |
| **Roblox Badges** | Display official Roblox account badges |
| **Recent Searches** | Save recent searches locally in the browser |
| **JSON API** | Access profile data through `/api/user/<username>` |
| **Share Profile** | Share profiles using the Web Share API with clipboard fallback |
| **Responsive UI** | Mobile-friendly Bootstrap 5 dark theme |
